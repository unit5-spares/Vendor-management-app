# AUTO PROFILES LIMITED – UNIT-III
## Vendor Repair Management Portal

Files:
- index.html
- app.js
- styles.css
- netlify.toml

### Current functionality
- Dashboard / Control Tower
- Repair request CRUD
- Vendor CRUD
- Equipment/spare master CRUD
- Challan tracking (manual physical challan; portal tracks readiness/reference)
- Due date and overdue monitoring
- Vendor management
- Reports and CSV export
- Browser localStorage persistence

### Important
This version is a fully functional browser-side portal. It is not yet a multi-user production backend. For company-wide deployment, connect Firebase/Supabase or another authenticated backend, then add role-based access, real-time synchronization, audit logs and scheduled notifications.
